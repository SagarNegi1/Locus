Locus — software and service requirements
===========================================

This is a Next.js / TypeScript application, not a Python project.
`package.json` and `package-lock.json` are the canonical dependency manifests;
install the exact locked dependency tree with: npm ci

Runtime
-------
- Node.js >= 20.9.0 (required by installed Next.js 16.3.4)
- npm (package-lock.json uses lockfile version 3)

External services and configuration
-----------------------------------
- Supabase: Auth, PostgreSQL database, and a `records` Storage bucket
- Google Gemini API: structured medical-PDF pre-check and extraction
- Google Cloud Document AI: optional OCR/layout API route
- Environment variables: see `.env.example`; never commit real values

Install and verify
------------------
1. npm ci
2. cp .env.example .env.local
3. Add service credentials to .env.local
4. npm run lint
5. npx tsc --noEmit
6. npm run build

For a complete setup guide, architecture, routes, safety limitations, and
submission notes, see README.md.
