Locus — software and service requirements
===========================================

Repository: https://github.com/SagarNegi1/Locus

This is a Next.js / TypeScript application, not a Python project.
`package.json` and `package-lock.json` are the canonical dependency manifests.
Install the exact locked dependency tree with:

    npm ci

Runtime
-------
- Node.js >= 20.9.0
- npm with lockfile v3 support

Application dependencies
------------------------
The exact versions are controlled by package.json and package-lock.json. The main runtime/service dependencies are:

- Next.js App Router
- React and React DOM
- TypeScript
- Tailwind CSS
- Radix UI / shadcn-style UI components
- Motion / Framer-style animation utilities
- lucide-react
- @google/genai
- @google-cloud/documentai
- @supabase/supabase-js
- react-pdf and PDF.js worker assets
- jspdf and jspdf-autotable

External services
-----------------
- Supabase Auth
- Supabase PostgreSQL database
- Supabase Storage bucket named `records`
- Google Gemini API for PDF pre-check and structured extraction
- Google Cloud Document AI for the optional OCR/layout endpoint

Required environment variables
------------------------------
See `.env.example`.

Verification commands
---------------------
1. npm ci
2. cp .env.example .env.local
3. Fill `.env.local` privately
4. npm run lint
5. npx tsc --noEmit
6. npm run build
7. npm run dev

Submission note
---------------
Do not commit `.env.local`, API keys, service-account files, real medical records, or private patient information.
